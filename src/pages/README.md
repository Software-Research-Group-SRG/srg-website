# pages/

This directory contains the main page components for the SRG Website. Each subdirectory or file represents a distinct route or section of the application, following a modular and scalable structure.

## Structure

- **about/**: About page components
- **landing/**: Landing (home) page components
- **leaders/**: Leaders page components
- **members/**: Members page components
- **partners/**: Partners page components
- **projects/**: Projects page components
- **README.md**: This documentation file

## Guidelines

- Each page should be placed in its own subdirectory for clarity and maintainability.
- Add another folder for each new page or section as needed.
- Keep page-specific logic and components within their respective folders.
- Shared components should be placed in `src/components/` or other appropriate shared directories.
